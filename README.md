# Rutab - Sistema de Gestión Logística 🚚

Este proyecto tiene como objetivo digitalizar y optimizar la logística de Distribuidora Los Alpes. La plataforma combina eficiencia operativa con un seguimiento en tiempo real de la flota, permitiendo a la empresa transformar sus datos logísticos en decisiones estratégicas.

## ⚠️ Requisitos Obligatorios

Para evitar conflictos de compatibilidad con Prisma y el entorno de ejecución, es **estrictamente necesario** usar la siguiente versión de Node:

- **Node.js:** v22.x.x (LTS)
- **Prohibido:** Node v24 (Causa errores internos en el CLI de Prisma).

## 🏗️ Estructura del Proyecto

El proyecto se divide en dos grandes bloques:

- **/backend/panel-admin**: API REST construida con NestJS y Prisma ORM.
- **/frontend**: Aplicación web SPA construida con React, Vite y TypeScript.

## 🛠️ Stack Tecnológico

- **Base de Datos:** PostgreSQL (Supabase).
- **Backend:** NestJS, Prisma, JWT, Bcrypt.
- **Frontend:** React 18, Vite, React Router, Context API.
- **Hosting:** Render (Backend) y Vercel (Frontend).
